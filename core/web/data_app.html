Une formule commence par =. Arguments séparés par ;, décimales avec un point dans les formules (=ARRONDI(B2*1.2;2)). Dans les cellules de valeur, la virgule française est comprise (3,5).

Références A1, absolues $A$1, plages A1:C10. Opérateurs + - * / ^ &, comparaisons = <> < > <= >=, pourcentage 50%. Attention : -2^2 vaut −4 (convention mathématique).

Équations

=RESOUDRE("x^3-2*x-5";2) racine près de 2 · =DERIVEE("x^2*SIN(x)";1) · =INTEGRALE("EXP(-x^2)";0;3). La variable est x ; l'expression peut lire des cellules ("B1*x^2-B2"). La valeur cible et les ajustements sont dans leurs onglets.
