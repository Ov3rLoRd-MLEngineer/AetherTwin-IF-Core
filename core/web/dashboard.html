      Ventilateurs et pompe

      Les ventilateurs de la carte mère se règlent par courbe température → vitesse dans le BIOS (Q-Fan), comme dans Armoury Crate (Fan Xpert). Le Hub lit ces courbes avec ton autorisation Windows ; il ne les modifie pas tant que la lecture réelle n'a pas été vérifiée.

      Inoue : optimiser le PC

      Inoue repère les programmes gourmands, la chauffe et le mode d'alimentation. Rien n'est fermé ni changé sans ton clic ; les processus de Windows et du Hub ne sont jamais proposés.

      Laboratoire : analyse FASTA

      Colle une ou plusieurs séquences au format FASTA. Longueur, composition, GC %, cadres de lecture ouverts (ORF) et protéine traduite : tout est calculé par le code, aucun modèle n'intervient.

      Calculatrice à calcul formel

      Résultats exacts et valeurs approchées, calculés sur cette machine (SymPy). Écris naturellement : 2x + 3x, x^2, solve(x^2 = 2, x). Définis avec := : a := 5, f(x) := x^2 + a. ans = dernier résultat.

        Mode manuel : zones posées à la main

        Pour une page où la détection rate des bulles. 1. Trace une boîte autour de chaque bulle, dans l'ordre de lecture (le numéro s'affiche). Les onomatopées et le texte hors bulle se posent avec l'outil Annexe (facultatif). 2. « Lire le texte », puis « Traduire » ; pendant la traduction, gomme ce qui doit disparaître. 3. « Réincruster ». La langue et le type de page sont ceux choisis plus haut.

        Glossaire d'une série

        Pour qu'une série garde les mêmes noms et les mêmes mots d'un chapitre à l'autre. Une entrée par ligne : langue d'origine = français. Seules les entrées présentes dans la page sont données au modèle. Le glossaire sert quand le champ « Série » en haut de l'onglet porte le même nom.
